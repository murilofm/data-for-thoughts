Aeroportos, partidas e retornos

Como os atrasos se distribuíam entre aeroportos brasileiros ao longo do dia?

3 dez 2013  ·  Subprojeto no GitHub

A série contém 284 boletins horários da Infraero e 12.846 registros de aeroportos.

Publicação original

Com um delay de mais de um ano, retomo com a esperança de atualizar o blog com certa frequência. Há duas razões principais para o retorno. Primeiro, há uma quantidade enorme de dados disponíveis subutilizados. Na minha opinião, isso deriva tanto da forma pouco eficiente de disponibilizá-los (tanto no sentido de disponibilizá-los de maneira inadequada quanto de dar pouca publicidade a eles) como da pouca familiaridade com ferramentas para análise dos mesmos. Esse segundo ponto se traduz na segunda razão para o retorno: há uma infinidade de maneiras de conseguir dados e tratá-los. Apesar de não ser especialista nem na análise dos dados nem na prospecção dos mesmos, se conseguir compartilhar parte das ferramentas que fui descobrindo (e for) e motivar alguma análise subsequente, terei atingido meu principal objetivo com a criação do blog.

Para (re)iniciar, compartilho um infográfico com dados de atrasos em vôos domésticos nos principais aeroportos brasileiros. Por algum tempo quis fazer algo com esses dados, mas isso só foi possível após a superação das seguintes etapas:

1) Prospecção dos dados: A Infraero disponibiliza de hora em hora uma tabela com o número de vôos por aeroportos e a quebra entre atrasados (até aquela hora do dia), atrasados na última hora e cancelados. Porém, criar uma série histórica com dados disponibilizados apenas pontualmente pela Infraero envolveu pensar e resolver as questões abaixo:
1.i) Qual linguagem de programação utilizar para conseguir os dados?
1.ii) Onde armazenar o programa?
1.iii) Onde armazenar os dados?
1.iv) Como fazer esse código rodar de hora em hora?
2) Tratamento e visualização dos dados: superada a etapa de conseguir as informações, o passo final era a apresentação dos dados de maneira clara. A ideia foi conseguir compatibilizar uma informação que é temporal (informação, de hora em hora, sobre os aeroportos) e outra que é espacial (aeroportos distribuídos pelo país).

O resultado desse exercício é a imagem abaixo; a imagem possui um link para o infográfico completo no qual é possível selecionar horários diferentes no slider localizado no canto inferior esquerdo. O infográfico apresenta o número de vôos atrasados por aeroporto no país. Cada aeroporto está representado por um círculo, e seu tamanho está associado a quantidade de atrasos. Além disso, o círculo assume a cor vermelha caso o número de atrasos esteja aumentando e azul se estiver diminuindo (em relação ao período anterior ao selecionado). O gráfico de barras no canto direito superior apresenta os aeroportos com maior número de atrasos e o gráfico de bolhas o número de vôos dos principais aeroportos.

Enfim, de tempos em tempos vou atualizar a série histórica para colocar mais dados no infográfico (é possível baixar os dados brutos a partir do link no centro, na parte inferior). Um trabalho interessante seria coletar os dados de cada companhia aérea, junto com as informação sobre origem e destino e as condições meteorológicas, e tentar identificar a existência (ou não) de algum tipo de efeito em cadeia nos atrasos. Nesse gráfico é possível ver alguns momentos em que ocorre uma proliferação dos atrasos, mas a interferência de um aeroporto em outro é pura suposição (o ideal seria que a mudança no período selecionado fosse mais rápida e que fosse possível testar a dependência da pontualidade dos vôos entre aeroportos). A título de informação, a apresentação dos dados foi feita usando o Tableau Public.
