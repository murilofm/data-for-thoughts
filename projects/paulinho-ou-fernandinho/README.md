[Abrir a publicação](https://murilofm.github.io/data-for-thoughts/projects/paulinho-ou-fernandinho/) · [Índice de subprojetos](../README.md)

**Edição publicada** · Mapas de passes originais recuperados

Os quadros do GIF publicado em 2014 permitem alternar os passes de cada jogador e a sobreposição.

## Executar

Na raiz do repositório, execute `python3 -m http.server 8000` e abra `http://localhost:8000/projects/paulinho-ou-fernandinho/`. Para gerar as páginas depois de editar as fontes, execute `python3 tools/build.py`.
