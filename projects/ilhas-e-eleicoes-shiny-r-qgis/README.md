## Executar

Na raiz do repositório, execute `python3 -m http.server 8000` e abra `http://localhost:8000/projects/ilhas-e-eleicoes-shiny-r-qgis/`. Para gerar as páginas depois de editar as fontes, execute `python3 tools/build.py`.
