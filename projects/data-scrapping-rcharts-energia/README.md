# Data Scrapping + rCharts + Energia

[Abrir a publicação](https://murilofm.github.io/data-for-thoughts/projects/data-scrapping-rcharts-energia/) · [Índice de subprojetos](../README.md)

Séries do setor elétrico ajudam a situar a discussão de 2014 sobre o abastecimento de energia.

**Edição publicada** · Visualização reconstruída

Série recuperada do gráfico rCharts de 2014. A visualização preserva os dias e valores ausentes.

## Executar

Na raiz do repositório, execute `python3 -m http.server 8000` e abra `http://localhost:8000/projects/data-scrapping-rcharts-energia/`. Para gerar as páginas depois de editar as fontes, execute `python3 tools/build.py`.
