# Artilheiros do Campeonato Brasileiro (2010-2012)

[Abrir a publicação](https://murilofm.github.io/data-for-thoughts/projects/artilheiros-campeonato-brasileiro/) · [Índice de subprojetos](../README.md)

Compare o perfil dos principais goleadores do Brasileirão de 2010, 2011 e parte de 2012.

**Edição publicada** · Heatmap reconstruído da figura

O infográfico publicou níveis de cor. As 144 células recuperam esses níveis e os campos ausentes; os valores brutos das nove métricas não foram publicados.

## Executar

Na raiz do repositório, execute `python3 -m http.server 8000` e abra `http://localhost:8000/projects/artilheiros-campeonato-brasileiro/`. Para gerar as páginas depois de editar as fontes, execute `python3 tools/build.py`.
