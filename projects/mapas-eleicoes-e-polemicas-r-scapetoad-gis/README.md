## Executar

Na raiz do repositório, execute `python3 -m http.server 8000` e abra `http://localhost:8000/projects/mapas-eleicoes-e-polemicas-r-scapetoad-gis/`. Para gerar as páginas depois de editar as fontes, execute `python3 tools/build.py`.
