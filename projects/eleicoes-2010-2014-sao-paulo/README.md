# Distribuição dos votos para presidente em São Paulo – 2010/2014 (R + Mapbox + Dimple.js)

[Abrir a publicação](https://murilofm.github.io/data-for-thoughts/projects/eleicoes-2010-2014-sao-paulo/) · [Índice de subprojetos](../README.md)

Uma comparação da distribuição dos votos para presidente na capital paulista nos primeiros turnos de 2010 e 2014.

## Executar

Na raiz do repositório, execute `python3 -m http.server 8000` e abra `http://localhost:8000/projects/eleicoes-2010-2014-sao-paulo/`. Para gerar as páginas depois de editar as fontes, execute `python3 tools/build.py`.
