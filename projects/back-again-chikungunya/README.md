# Back again [Chikungunya]

[Abrir a publicação](https://murilofm.github.io/data-for-thoughts/projects/back-again-chikungunya/) · [Índice de subprojetos](../README.md)

Um diário pessoal de 2016 acompanha a evolução dos sintomas ao longo do tempo.

**Edição publicada** · Relato pessoal com gráfico recuperado

O gráfico reproduz a forma das curvas desenhadas pelo autor. A escala vertical é qualitativa. Os pontos digitalizados descrevem o traçado de uma pessoa.

## Executar

Na raiz do repositório, execute `python3 -m http.server 8000` e abra `http://localhost:8000/projects/back-again-chikungunya/`. Para gerar as páginas depois de editar as fontes, execute `python3 tools/build.py`.
